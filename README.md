# AUSFIG X

Локальное шифрование сообщений в браузере. Публичный режим позволяет шифровать и расшифровывать сообщения по отдельному паролю без аккаунта. В приватном режиме доступны доверенные контакты, обмен ключами и локальное зашифрованное хранилище.

## Работа с приложением

Откройте статический сайт по HTTPS, введите сообщение и используйте парольную фразу не короче 16 символов либо нажмите «Сгенерировать стойкий пароль». Сохраните пароль **до** шифрования и передайте собеседнику отдельно от кода Q1:. Старые Q1-коды с короткими паролями по-прежнему можно расшифровать.

Для доверенных контактов откройте «Доверенные контакты», создайте локальный профиль и сверьте отпечатки ключей с собеседником. При сворачивании окна приватный профиль блокируется. После успешной установки service worker публичная и приватная части доступны офлайн. Для первого скачивания файлов нужен интернет.

## Проверка

Требуется Node.js 22+:

```bash
npm test
```

Тесты проверяют быстрое шифрование, совместимость ранее созданных кодов, защиту от повреждения кода и основные регрессии интерфейса и офлайн-кэша. Это не заменяет независимый аудит криптографической реализации и тестирование в реальных браузерах.

## Ограничения безопасности

Приложение не доставляет сообщения на сервер, а работает локально. Парольную фразу необходимо передавать отдельно от шифртекста. Это предварительная веб-реализация без независимого криптографического аудита; скомпрометированное устройство или подмена опубликованного веб-кода могут раскрыть данные. Не используйте приложение для критически важных секретов без дополнительной проверки.
