# AUSFIG X

Веб-приложение для локального шифрования сообщений. Открывается по HTTPS на телефоне и компьютере; может устанавливаться как PWA и работать без сети после загрузки офлайн-ресурсов.

**Статус: предварительная веб-реализация 0.1, без независимого аудита.** Это адаптация приложенного ТЗ, а не готовое нативное Android-приложение. Перед использованием для чувствительных данных необходим независимый анализ кода, протокола и размещения.

## Возможности

- Создание локального хранилища под парольной фразой, минимум 12 символов.
- Двусторонний обмен публичными ключами X25519 текстом или QR-кодами.
- Ручная проверка полного отпечатка перед сохранением контакта.
- ChaCha20-Poly1305, раздельные цепочки ключей для направлений, счётчики и защита от повторного принятия.
- Обычный текст UTF-8 до 4096 байт; словарные команды в коде M1 из 33 символов.
- До 100 пропущенных ключей на контакт для сообщений не по порядку.
- Копирование кода, сохранение текстового файла, QR-генерация и сканирование камерой.
- Зашифрованная база IndexedDB, атомарное сохранение с проверкой ревизии между вкладками.
- Блокировка при уходе страницы в фон и через 5 минут бездействия.
- Все зависимости встроены в сборку; CDN, аналитика и сервер обработки сообщений отсутствуют.

## Опубликовать через GitHub Pages

В репозитории уже есть готовая папка `docs/`. Устанавливать Node.js для публикации готовых файлов не нужно.

1. Создайте репозиторий `ausfig-x` на GitHub. Для бесплатного размещения Pages обычно используется публичный репозиторий. Не добавляйте реальные ключи, сообщения или данные браузера.
2. Загрузите **содержимое распакованного проекта**, сохранив структуру папок. ZIP-файл сам по себе не запускает приложение.
3. Откройте **Settings → Pages**.
4. В **Build and deployment → Source** выберите **Deploy from a branch**.
5. Выберите ветку **main**, папку **/docs**, нажмите **Save**.
6. Дождитесь успешного задания `pages build and deployment` во вкладке **Actions**. Адрес приложения появится в **Settings → Pages**.
7. Откройте этот адрес в браузере телефона или ПК. Для криптографии, камеры и PWA нужен HTTPS. Открытие `index.html` через `file://` не поддерживается.

Ссылка на репозиторий показывает исходный код. Приложение открывается по отдельной ссылке **GitHub Pages**. Адрес вида `https://ВАШ-ЛОГИН.github.io/ausfig-x/` приведён как шаблон, а не подтверждение публикации.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Первый обмен

1. На каждом устройстве создайте профиль со своей сильной парольной фразой.
2. Устройство А: **Обмен ключами → Я начинаю обмен → Создать приглашение**.
3. Устройство Б: **У меня есть приглашение**. Вставьте или отсканируйте приглашение, создайте ответ.
4. Передайте ответ на устройство А и нажмите **Проверить отпечаток**.
5. Лично или по независимому доверенному каналу сравните **весь** отпечаток на обоих экранах. При несовпадении отмените обмен.
6. На обоих устройствах задайте имя контакта, подтвердите совпадение и сохраните контакт.
7. Шифруйте код на одном устройстве, передавайте любым выбранным каналом, расшифровывайте на другом с выбранным контактом.

Незавершённое сопряжение удаляется при блокировке. При переключении в другое приложение страница блокируется: удобнее завершать первый обмен между рядом расположенными устройствами через QR. Коды приглашений содержат только публичные данные.

Приложение **не доставляет** сообщения автоматически. Телефон и компьютер имеют независимые хранилища. Пароль одного устройства не переносит контакты на другое.

## Установка и офлайн

- Android / Chrome: меню браузера → **Установить приложение** или **Добавить на главный экран**.
- iPhone / Safari: **Поделиться → На экран Домой**.
- ПК / Chrome или Edge: установка через адресную строку или меню браузера, если доступна.
- Дождитесь **Безопасность → Офлайн-ресурсы → Готово без сети** перед отключением интернета.

Поддержка установки зависит от браузера. Кэш и IndexedDB могут быть удалены браузером или пользователем. Не используйте приватный режим для постоянного хранения. Первичная загрузка и обновление приложения требуют сети. Хостинг обслуживает файлы и может регистрировать запросы к ним. Текст и ключи приложение не отправляет.

## Разработка

Требуется Node.js 20.19+ (рекомендуется актуальная LTS).

```sh
npm ci
npm test
npm run build
```

Сборка обновляет `dist/` и готовую папку `docs/`. Для локального запуска можно использовать любой статический сервер на localhost, например:

```sh
python3 -m http.server 8080 --directory docs
```

Откройте `http://localhost:8080`. Для доступа с другого устройства нужен HTTPS; обычный HTTP по LAN-адресу не предоставляет все API безопасности.

После изменения исходников выполните тесты, сборку и закоммитьте `src/`, `public/`, `docs/`, `dist/` и изменённые метаданные зависимостей. GitHub Pages автоматически перепубликует `docs/` после изменения выбранной ветки. Service worker активирует новую версию после закрытия старых вкладок приложения. Не обновляйте приложение посреди обмена.

## Соответствие ТЗ и ограничения

Реализованы основные сценарии локального обмена, криптографические примитивы, M1, сеансы, QR, счётчики и защищённое хранение. Произвольный текст имеет отдельный префикс T1. Детали протокола, отсутствующие в концепции, конкретизированы в `PROTOCOL.md`; совместимость с любой будущей нативной реализацией требует отдельных тестов.

**В веб-версии не реализованы:** Android Keystore / iOS Secure Enclave, биометрия, запрет снимков экрана, подписанный APK, резервные копии Argon2id, Bluetooth и независимый аудит. Локальное хранилище защищено AES-256-GCM с ключом из PBKDF2-HMAC-SHA256 (600 000 итераций, случайная соль 16 байт); это не аппаратная защита. Установка PWA не делает приложение эквивалентным нативной реализации.

Активные состояния сеансов нельзя восстанавливать из старых копий. Экспорта/импорта активных состояний нет. При потере пароля или очистке браузера нужен новый профиль и новое сопряжение. Компрометация сайта, расширения браузера, операционной системы или разблокированного устройства может раскрыть текст и ключи.
